# JOVI - Smart Study
## Sobre o projeto
O JOVI é uma plataforma desenvolvida para auxiliar estudantes em sua organização e jornada de aprendizagem.
O projeto foi evoluído na Sprint 4, com integração ao React, React Router e Tailwind CSS.

## Tecnologias utilizadas
- React
- JavaScript
- Vite
- Tailwind CSS 4
- React Router
- HTML
- CSS

## Funcionalidades
- Landing Page
- Cadastro
- Login
- Autenticação de demonstração
- Armazenamento de sessão com LocalStorage
- Rotas públicas e privadas
- Painel do estudante
- Consulta de frases por API externa

## Instalação

Clone o repositório:
git clone 
Entre na pasta:
cd jovi-react
Instale as dependências:
npm install

## Executar o projeto

npm run dev

## Compilar para produção

npm run build
